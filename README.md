# Laboratorios de Java — Proceso Formativo ADSO

Repositorio oficial que recopila los laboratorios prácticos y retos integradores desarrollados en Java durante el proceso formativo en Análisis y Desarrollo de Software.

## 📂 Contenido del Repositorio

### [Laboratorio 01 — Primeros pasos con Java](./laboratorio-01/)
* **Temas:** Verificación del entorno, variables, tipos de datos, operadores aritméticos, entrada de datos mediante `Scanner`.
* **Reto Integrador:** `CotizadorCompra.java` (cálculo de subtotales, descuentos, impuestos y totales de compra).

### [Laboratorio 02 — Decisiones, ciclos y métodos en Java](./laboratorio-02/)
* **Temas:** Expresiones booleanas, estructuras condicionales (`if`, `else if`, `else`), selección múltiple (`switch`), ciclos de repetición (`for`, `while`, `do-while`), contadores, acumuladores, métodos estáticos, parámetros y valores de retorno.
* **Reto Integrador:** `BilleteraConsola.java` (gestión interactiva de saldo, registro de ingresos y gastos con validaciones mediante un menú persistente).
